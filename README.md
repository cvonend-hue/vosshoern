# Phoshorn Webseite

Arbeitsprojekt für die geplante Neugestaltung von [Das Vosshörn](https://www.vosshoern.de/).

## Stand

Die bestehende Website wurde am 18. Oktober 2026 aufgenommen. Die Ergebnisse stehen in [docs/bestandsaufnahme.md](docs/bestandsaufnahme.md). Das neue Designkonzept und damit die Umsetzung folgen.

## Ziel

- Neugestaltung auf Basis des noch folgenden Designkonzepts
- Nachvollziehbare Änderungen mit Git und GitHub
- Passwortgeschützte Demo auf Cloudflare vor einer Veröffentlichung

Die bestehende Website bleibt während der Arbeit unverändert. Vor einer Umsetzung werden Preise, Konditionen, Angebote und rechtliche Texte mit der Inhaberin abgeglichen.
